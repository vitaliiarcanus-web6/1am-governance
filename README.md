# 1AM Governance

Canonical public governance layer of 1AM Universe — 1AM Manifesto & 1AM CODEX. Human + AI. Together, not against each other.

This repository distributes two approved governance texts. The [Manifesto](manifesto/1AM_Manifesto_v1.1_CANONICAL.txt) states the values; the [CODEX](codex/1AM_CODEX_v1.0_CANONICAL.txt) states operational principles for AI decisions. The canonical `.txt` files take precedence over explanatory or machine readable derivatives.
